## 1. Analisis Komparatif Platform

Platform merupakan lingkungan yang digunakan untuk menjalankan aplikasi. Setiap platform memiliki karakteristik, teknologi, keunggulan, dan keterbatasan yang berbeda.

| Aspek           | Web                                                                                                                                        | Desktop                                                                                                                                      | Mobile                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Bahasa utama    | HTML, CSS, JavaScript, dan bahasa backend seperti PHP atau Python                                                                          | Java, C#, C++, Python, dan JavaScript                                                                                                        | Kotlin, Java, Swift, dan Dart                                                                                      |
| Arsitektur      | Umumnya menggunakan arsitektur client-server. Aplikasi diakses melalui browser dan dapat terhubung ke server.                              | Aplikasi berjalan di sistem operasi komputer dan dapat mengakses sumber daya lokal sesuai izin.                                              | Aplikasi berjalan pada sistem operasi perangkat mobile, seperti Android dan iOS, dengan akses ke fitur perangkat.  |
| Cara distribusi | Melalui URL dan dapat diakses menggunakan browser tanpa instalasi aplikasi konvensional.                                                   | Umumnya melalui installer, paket aplikasi, atau toko aplikasi desktop.                                                                       | Melalui toko aplikasi seperti Google Play Store dan Apple App Store, atau melalui metode distribusi lainnya.       |
| Keunggulan      | Mudah diakses dari berbagai perangkat, pembaruan dapat dilakukan di server, dan pengguna tidak harus memasang aplikasi secara terpisah.    | Dapat memanfaatkan sumber daya komputer secara optimal dan cocok untuk aplikasi yang membutuhkan fitur sistem operasi atau pemrosesan lokal. | Praktis digunakan, mudah dibawa, dan dapat memanfaatkan fitur seperti kamera, GPS, serta sensor perangkat.         |
| Keterbatasan    | Ketergantungan pada browser dan koneksi internet dapat menjadi kendala, terutama untuk aplikasi yang membutuhkan akses perangkat tertentu. | Pengembangan dan distribusi dapat memerlukan penyesuaian terhadap sistem operasi, serta instalasi pada perangkat pengguna.                   | Memiliki keterbatasan ukuran layar, sumber daya baterai, serta perbedaan sistem operasi dan spesifikasi perangkat. |
| Contoh aplikasi | Google Docs, Gmail, dan Google Drive versi web                                                                                             | Microsoft Word versi desktop, Visual Studio Code, dan VLC Media Player                                                                       | WhatsApp, Google Maps, dan aplikasi mobile Spotify                                                                 |
